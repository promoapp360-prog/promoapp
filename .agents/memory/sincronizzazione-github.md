---
name: Sincronizzazione GitHub PromoApp
description: Regola di sincronizzazione del progetto PromoApp con il repository GitHub del progetto
---

Prima di lavorare sul progetto, controllare se il repository GitHub contiene aggiornamenti remoti e integrarli quando non ci sono conflitti. Dopo le modifiche richieste al progetto, sincronizzarle con GitHub e verificare che i due riferimenti coincidano.

**Why:** l’utente ha chiesto che gli aggiornamenti siano controllati e sincronizzati in entrambe le direzioni da questo momento in poi.

**How to apply:** applicare la regola al solo progetto PromoApp e al suo repository GitHub dedicato. Non sovrascrivere modifiche locali o remote in conflitto; fermarsi e chiedere come risolvere. Non sincronizzare altri progetti o repository.
