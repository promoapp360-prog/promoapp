---
name: Aggiunta progetti lavori
description: Distinzione tra ambienti e preservazione dei dati nelle anteprime cliente
---

Le anteprime dei progetti cliente hanno dati distinti tra sviluppo e produzione. Un progetto creato solo in sviluppo non appare automaticamente sul sito pubblico.

**Why:** in precedenza, la sola creazione in sviluppo lasciava il progetto assente sul sito live.

**How to apply:** quando l'utente chiede un progetto visibile anche sul sito pubblico, verificare entrambi gli ambienti ed eseguire le operazioni autorizzate tramite le funzionalità amministrative esistenti.

Non sovrascrivere l'intero database pubblico per trasferire un singolo progetto o altri dati applicativi.

**Why:** il database pubblico contiene altri dati da preservare.

**How to apply:** usare una procedura amministrativa mirata, senza pubblicare o memorizzare credenziali, password dei progetti o identificativi privati nella documentazione.
